# 🎯 SSAFY 싸피데이 인물 맞추기 게임 가이드 (6세트 대항전)

싸피데이 레크리에이션을 위해 제작된 **인물 맞추기 게임(웹 애플리케이션)**입니다.  
프로젝터 화면(1080p 등) 어디서든 **스크롤 없이 100vh 한 화면에 완벽 핏팅**되며, 실제 예능(신서유기/지락실) 방식의 쫄깃한 릴레이 인물 퀴즈와 공정한 조별 대항전을 즐기실 수 있습니다.

---

## 🏆 핵심 게임 룰 요약

1. **총 6세트(게임) 대항전**
   - 각 세트는 **20문제 연속 릴레이**로 진행됩니다.
   - 1인 1게임 참여 원칙 (단, 인원이 부족한 5인 조는 1번 타자가 6게임에 한 번 더 출전 가능).
2. **타자 로테이션**
   - **1~5게임:** 각 조의 1번 ~ 5번 타자가 순서대로 출전
   - **6게임 (파이널):** 6인 조는 6번 타자 출전 / 5인 조는 **1번 타자 재출전**
3. **실패 즉시 토스 룰 (스틸)**
   - 문제를 틀리면("땡!" / `X`), 사진이 가려지지 않고 **그대로 노출된 상태에서 즉시 다음 조 도전자에게 기회가 토스**됩니다.
   - 누구든 먼저 맞히는 조가 해당 문제의 점수를 획득합니다.
4. **다음 게임 선택권**
   - 20번째(세트 마지막) 문제를 맞힌 사람이 **다음 게임의 카테고리와 난이도를 직접 선택**합니다.
5. **조 순서 랜덤 추첨 (Order Randomizer)**
   - 카테고리와 단계를 고르면, 출전 타자 4명의 도전 순서(1~4번)를 긴장감 넘치는 **룰렛 애니메이션으로 랜덤 추첨**한 뒤 퀴즈 화면으로 진입합니다.
6. **사진 뷰어 풀뷰 (Contain)**
   - 사진이 잘리거나 찌그러지지 않고, **모든 부분이 100% 온전히 보이도록 대형 뷰어(`object-fit: contain`)**가 적용되어 있습니다.

## 🚀 게임 진행 흐름

### 1단계: 📜 [화면 0] 룰북 화면 (시작 화면)
- 6세트 대항전, 타자 로테이션, 랜덤 순서 추첨, 실패 즉시 토스 룰을 브리핑합니다.
- 브리핑 후 **`[👥 팀 배정 & 타자 순번 확인 ➡️]`** 버튼을 클릭합니다.

### 2단계: 👥 [화면 1] 룰렛 랜덤 배정 & 타자 명단 확정
- **🎲 [룰렛 랜덤 배정]**:
  - 버튼 클릭 시 참여 인원이 4개 조에 균등하게 자동 분배됩니다.
  - 마우스 드래그 & 드롭으로 1번~6번 타자 순서를 자유롭게 조정할 수 있습니다.
- **❌ 불참/조퇴 인원 관리**:
  - 명찰 우클릭(또는 ✕ 버튼)으로 즉시 제외할 수 있으며 상단 복구 칩에서 언제든 복원 가능합니다.
- 세팅 완료 후 상단 **`[🎯 게임 보드판으로 🚀]`** 버튼 클릭!

### 3단계: 🎯 [화면 2] 카테고리 & 단계 선택 보드판
- 총 15개 블록(5개 카테고리 × 3단계, 각 20문제)으로 구성되어 있습니다.
- 각 버튼에는 난이도를 직관적으로 체감할 수 있는 **배경 이미지(침착맨, 원피스, 나루토 등)**가 은은하게 적용되어 있습니다.
- 상단 배너에 **직전 세트 20번 정답자(선택권자)**의 이름이 황금 배너로 표시됩니다.
- 원하는 카드를 클릭하면 **조 순서 랜덤 추첨 화면**으로 이동합니다.

### 4단계: 🎲 [화면 3] 조 순서 랜덤 추첨 화면
- 이번 세트에 출전하는 4개 조의 대표 타자 4명이 등장합니다.
- **`[🎲 도전 순서 랜덤 추첨하기]`** 버튼을 누르면 긴장감 넘치는 사운드와 함께 카드 셔플 룰렛이 회전합니다.
- 1번째 ~ 4번째 도전 순서가 확정되면 **`[🔥 이 순서로 퀴즈 시작! 🚀]`** 버튼을 눌러 출제 화면으로 돌입합니다.

### 5단계: 🖼️ [화면 4] 20문제 연속 릴레이 & 즉시 토스 퀴즈
1. **문제 대기**:
   - 상단에 현재 도전 순번 체인(1조 ➔ 3조 ➔ 2조 ➔ 4조)과 현재 타자 이름이 표시됩니다.
   - 중앙 가림막에 **`🎯 [O조 OOO] 차례!`**가 큼직하게 뜹니다.
2. **스페이스바 (`Space`) 클릭**:
   - 가림막이 열리며 왜곡 없이 전체가 온전히 보이는 대형 사진이 공개됩니다.
   - MC가 구두로 **"하나, 둘, 셋!"** 카운트다운을 외칩니다.
3. **정답 인정 (`O` 키 또는 버튼)**:
   - 정답 효과음과 함께 점수가 반영되고, 즉시 다음 문제(다음 타자)로 넘어갑니다.
4. **땡! 실패 (`X` 키 또는 버튼)**:
   - "땡!" 버저음과 함께 **사진이 유지된 채 즉시 다음 순서 조 도전자에게 기회가 넘어갑니다!**
   - 상단에 **`⚡ 땡! ➔ 기회 토스: [다음 조 OOO]`** 배너가 번쩍입니다.
5. **20문제 완주 시**:
   - 20번째 문제를 맞힌 도전자에게 축하 팡파레와 함께 **다음 게임 선택권 안내 모달**이 뜹니다.
   - 6게임(최종전)이 종료되면 시상대 화면으로 자동 전환됩니다.

### 6단계: 👑 [화면 5] 최종 시상식 (Final Podium)
- 6세트가 모두 종료되면 축하 팡파레와 꽃가루 효과와 함께 1위부터 4위까지 순위와 최종 누적 점수가 발표됩니다.

## ⌨️ MC 단축키 치트시트

| 키 | 기능 | 설명 |
| :---: | :--- | :--- |
| **`Space`** | **사진 공개 / 정답 확인** | 1번 누르면 사진 공개(구두 카운트), 2번 누르면 정답 박스 오픈 |
| **`O`** (또는 `ㅐ`) | **정답 인정** | 점수 추가 + 다음 문제 및 다음 순서 타자로 즉시 전환 |
| **`X`** (또는 `ㅌ`) | **땡! (실패 & 토스)** | 버저음 + **사진 유지된 채 다음 조 타자에게 기회 즉시 토스** |
| **`→`** (또는 `N`) | **문제 넘기기** | 현재 문제 스킵하고 다음 타자에게 차례 전환 |
| **`Esc`** | **카테고리판 복귀** | 진행 중 메인 보드판으로 복귀 |
| **`B`** (또는 `ㅠ`) | **BGM 켜기/끄기** | 배경음악 음소거 토글 |
