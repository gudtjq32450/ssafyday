# 🎯 SSAFY 싸피데이 인물 맞추기 게임 가이드

싸피데이 레크리에이션을 위해 제작된 **인물 맞추기 게임(웹 애플리케이션)**입니다.  
프로젝터 화면(1080p 등) 어디서든 **스크롤 없이 100vh 한 화면에 완벽 핏팅**되며, 실제 예능(신서유기/지락실) 방식의 쫄깃한 릴레이 인물 퀴즈를 즐기실 수 있습니다.

---

## 🚀 게임 진행 흐름 (예능식 연속 릴레이 완벽 구현!)

### 1단계: 📜 [화면 0] 룰북 화면 (시작 화면)
- 4개 조 대항전, 카테고리 릴레이 룰, 스페이스바 사진 공개, 스틸 규칙을 브리핑합니다.
- 브리핑 후 **`[👥 팀 배정 & 순서 정하러 가기 ➡️]`** 버튼을 클릭합니다.

### 2단계: 👥 [화면 1] 룰렛 랜덤 배정 & 조별 순서 확인
- **🎲 [룰렛 랜덤 배정]**:
  - 버튼 클릭 시 **현재 참여하는 인원 수에 맞춰 4개 조에 가장 균등하게(최대 차이 1명 이내) 자동 분배**됩니다!
  - 셔플 후에도 조끼리 상의하여 **명찰을 마우스로 위아래로 끌어당겨 순서(1번~6번)를 즉석에서 변경**할 수 있습니다.
- **❌ 조퇴 / 결석 / 미참여 인원 우클릭 삭제**:
  - 명찰을 **마우스 우클릭(또는 ✕ 버튼 클릭)**하면 즉시 제외되며, 룰렛을 다시 돌려도 절대 살아나지 않습니다.
  - 제외된 인원은 상단 `🚫 제외/결석 인원` 칩을 클릭해 언제든 복구 가능합니다.
- 세팅 완료 후 상단의 **`[🎯 문제 선택판으로 🚀]`** 버튼을 누릅니다.

### 3단계: 🎯 [화면 2] 카테고리 및 단계(1~3단계 각 20문제) 선택 보드판
- 5개 카테고리 컬럼마다 **⭐ 1단계, ⭐⭐ 2단계, ⭐⭐⭐ 3단계 (각 20문제 릴레이 라운드)** 카드가 배치되어 있습니다.
- 원하는 단계 카드를 클릭하면 해당 단계의 **20문제 연속 릴레이**가 시작됩니다! (~20명 반 전체가 한 번씩 도전!)
- 20문제를 완주하면 보드판 해당 카드에 **굵은 빨간 ❌표**가 쳐지며 완료 상태가 됩니다.

### 4단계: 🖼️ [화면 3] 20문제 연속 릴레이 출제 & 스페이스바 사진 공개
1. **대기 화면 ("~~ 차례!")**:
   - 화면 중앙에 사진이 가려진 채 **`🎯 1조 1번 [최기영] 차례!`**가 대문짝만하게 뜹니다.
2. **스페이스바 (`Space`) 클릭**:
   - 가림막이 사라지며 **사진이 촥! 공개**됩니다!
   - 별도 타이머 없이 MC가 입으로 **"하나, 둘, 셋!"** 카운트다운을 외칩니다.
3. **정답 인정 (`O` 키 또는 버튼)**:
   - 딩동댕~ 소리와 함께 현재 도전자 조에 점수가 합산됩니다.
   - **화면 이동 없이 즉시 다음 문제로 넘어가며, 가림막이 덮이고 `🎯 2조 1번 [김영웅] 차례!`로 자동 변경**됩니다!
   - 다시 스페이스바를 누르면 2조 1번의 문제가 시작됩니다. (3-1 ➔ 4-1 ➔ 1-2 순서로 착착 진행)
4. **땡! 실패 (`X` 키 또는 버튼)**:
   - 실패 버저음과 함께 **`[스틸 찬스 (+10점)]`** 버튼이 활성화됩니다.
   - 다른 조가 맞히면 해당 조에 10점을 부여하고 다음 타자로 넘어가며, 패스(`→` 키)하면 다음 타자에게 차례가 넘어갑니다.
5. **20문제 완주 시**:
   - 팡파레와 함께 20문제 완주 알림이 뜨며 보드판으로 자동 복귀하여 **❌표**가 마킹됩니다.

## ⌨️ MC 단축키 치트시트

| 키 | 기능 | 설명 |
| :---: | :--- | :--- |
| **`Space`** | **사진 공개 / 정답 확인** | 1번 누르면 사진 공개(MC가 구두 카운트), 2번 누르면 정답 박스 공개 |
| **`O`** (또는 `ㅐ`) | **정답 인정** | 점수 추가 + **같은 카테고리의 다음 문제 & 다음 타자(2-1, 3-1...)로 즉시 전환** |
| **`X`** (또는 `ㅌ`) | **땡! (실패)** | 버저음 + 스틸 찬스 버튼 등장 |
| **`→`** (또는 `N`) | **다음 문제/타자 넘기기** | 패스하고 다음 사람 차례로 즉시 전환 |
| **`Esc`** | **카테고리판 복귀** | 즉시 메인 보드판으로 복귀 |
| **`B`** (또는 `ㅠ`) | **BGM 켜기/끄기** | 배경음악 음소거 토글 |

## 📁 퀴즈 사진 등록 방법 (2가지 지원)

### 방법 1. 로컬 이미지 폴더에 사진 파일 넣기 (가장 추천! 🚀)
- `인물퀴즈/images/` 폴더에 아래 규칙으로 사진 파일을 넣어두면 브라우저에서 자동 인식합니다.
- **파일명 규칙:** `{카테고리ID}_l{단계}_q{문제번호}.jpg`
- **카테고리 ID:**
  - `anime` : 애니 & 캐릭터
  - `actor` : 배우 & 방송인
  - `music` : 가수 & 아이돌
  - `youtube` : 유튜버 & 크리에이터
  - `general` : 종합 & 일반인
- **파일명 예시:**
  - `anime_l1_q1.jpg` ~ `anime_l1_q20.jpg` (애니 1단계 1번~20번)
  - `actor_l2_q5.jpg` (배우 2단계 5번)
  - `music_l3_q12.jpg` (가수 3단계 12번)
  - `youtube_l1_q1.jpg` (유튜버 1단계 1번)
  - `general_l1_q20.jpg` (종합 1단계 20번)

### 방법 2. 웹 브라우저에서 직접 등록 (드래그 & 드롭)
- 문제를 열었을 때 사진 영역(또는 "문제 수정" 모달)에 이미지 파일을 끌어다 놓거나 클릭하여 업로드하면 브라우저 LocalStorage에 자동 압축되어 즉시 반영됩니다.
